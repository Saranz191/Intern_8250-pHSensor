# NUCLEO-L432KC Four-Channel pH Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a safe, buildable STM32CubeIDE `main` branch that gives an intern layered C stubs for a four-channel SIC8250 pH assignment without supplying the FSM, register sequence, channel scheduler, or conversion solution.

**Architecture:** STM32CubeMX generates a NUCLEO-L432KC project with no application SPI/GPIO assignments. `main.c` calls a thin Application layer; the Application owns four channel contexts and a deliberately incomplete FSM; the SIC8250 driver exposes operation-level stubs; and the BSP exposes configurable hardware callbacks without selecting real pins or peripherals.

**Tech Stack:** C11, STM32CubeMX, STM32CubeIDE, STM32Cube FW L4 V1.18.2, STM32 HAL/CMSIS, Git.

## Global Constraints

- Target board: NUCLEO-L432KC with STM32L432KC.
- Create and publish only the `main` branch.
- `PH_CHANNEL_COUNT` is exactly `4U`.
- Do not configure the application SPI peripheral, chip-select, reset, or power GPIO.
- Do not copy `macallan_low_leakage_dropper_sum.py` or `generated_registers.py`.
- Do not include SIC8250 register addresses, masks, configuration values, write order, channel-selection expression, FSM transition table, ADC conversion formula, or pH conversion formula.
- Do not create automated tests, test directories, fake BSP code, host CMake, or CI workflows.
- The initial firmware must remain in safe idle and perform no SIC8250 I/O.
- Verify completion by building the STM32CubeIDE Debug configuration, not by adding tests.

- [ ] **Step 2: Add the board port**

Define the board contract exactly as:

```c
typedef enum {
    PH_BOARD_STATUS_OK = 0,
    PH_BOARD_STATUS_NOT_CONFIGURED,
    PH_BOARD_STATUS_INVALID_ARGUMENT,
    PH_BOARD_STATUS_IO_ERROR
} ph_board_status_t;

typedef struct {
    void *context;
    ph_board_status_t (*spi_write_reg)(
        void *context,
        uint8_t address,
        uint8_t value);
    ph_board_status_t (*spi_read_reg)(
        void *context,
        uint8_t address,
        uint8_t *value);
    uint32_t (*millis)(void *context);
    ph_board_status_t (*set_power)(void *context, bool enabled);
    ph_board_status_t (*set_reset)(void *context, bool asserted);
} ph_board_port_t;

const ph_board_port_t *ph_board_port_default(void);
```

Include `<stdbool.h>` and `<stdint.h>`. The default implementation:

- ignores every input safely;
- returns `PH_BOARD_NOT_CONFIGURED` for SPI and control calls;
- returns `0U` for time;
- contains no STM32 HAL include and no peripheral or pin identifier.

Expose:

```c

    ph_fsm_t *fsm,
    const ph_dependencies_t *dependencies);

```

`ph_fsm_init()` sets safe idle, channel zero, and not-implemented status.
`ph_fsm_process()` returns not implemented without changing state or touching
the driver. `ph_fsm_stop()` restores safe idle without touching hardware.
`ph_fsm_get_status()` returns invalid argument for a null context and otherwise
returns the saved status.
